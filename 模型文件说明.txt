========================================
  3D模型文件大小问题解决方案
========================================

问题：你的模型文件 test.glb 为 2.7MB，超过微信小程序2MB限制

========================================
解决方案（3选1）
========================================

方案1：压缩模型文件 ⭐推荐
-----------------------------------------
使用在线工具压缩GLB文件：
1. 访问 https://gltf.report/ 或 https://glb.jonshamir.com/
2. 上传你的 test.glb 文件
3. 调整压缩参数，目标压缩到 1.5MB 以下
4. 下载压缩后的文件
5. 替换 miniprogram/models/test.glb

方案2：使用网络URL加载 ⭐推荐
-----------------------------------------
1. 将 test.glb 上传到以下任意位置：
   - 自己的服务器
   - 腾讯云COS（对象存储）
   - 阿里云OSS
   - 七牛云
   - GitHub（使用jsdelivr CDN加速）

2. 获取文件的HTTPS URL

3. 修改 miniprogram/pages/index/index.js 文件：
   找到第57行左右：
   const modelUrl = 'https://your-server.com/test.glb'
   
   替换为你的URL，例如：
   const modelUrl = 'https://example.com/models/test.glb'
   
   然后将第62行改为：
   const useLocalFile = false

4. 在 project.config.json 中添加域名白名单（如果需要）

方案3：使用微信云开发存储
-----------------------------------------
1. 在微信开发者工具中开通云开发
2. 上传模型到云存储
3. 获取文件的云存储URL
4. 按照方案2修改代码，使用云存储URL

========================================
推荐方案组合
========================================

最佳实践：先压缩（方案1），再使用网络URL（方案2）

1. 压缩模型到 1-1.5MB
2. 上传到服务器获取URL
3. 使用网络加载，真机预览不受2MB限制

========================================
临时测试方案
========================================

如果只是想快速测试，可以：
1. 使用更小的测试模型（<2MB）
2. 或者在开发者工具中测试（不真机预览）
