# 圆明园3D文物展示小程序
> 微信原生小程序 + Three.js 实现文物3D模型在线预览，结合腾讯云开发实现后端数据服务。

## ✨ 项目简介
本项目是面向圆明园文物数字化展示的微信小程序，支持在小程序内加载、渲染GLB三维文物模型，提供文物信息浏览、收藏、详情介绍等功能。
> 项目现状说明（面试重点）：
> 1. 腾讯云开发资源已过期释放，云函数无法在线调用；
> 2. 微信基础库版本迭代，小程序XR/3D渲染接口存在兼容性问题，当前新版本微信无法正常展示3D模型；
> 3. 47M文物模型文件`glb_head.bin`因体积较大，**未提交至Git仓库**，代码内保留完整模型加载逻辑。

## 🛠 技术栈
- 前端：微信原生小程序 WXML/WXSS/JS，Three.js，小程序XR组件
- 后端：腾讯云开发（CloudBase），云函数
- 3D：GLB格式三维模型，前端WebGL渲染

## 📁 目录结构
├── miniprogram/            # 小程序前端代码
│   ├── components/         # 自定义组件（3D 模型查看器 xr-model-viewer、自定义 tabbar）
│   ├── pages/              # 页面：首页、文物赏析、收藏、详情页、关于页
│   ├── images/             # 页面静态图片资源
│   ├── models/             # 模型相关 JS 逻辑
│   ├── app.js/app.json     # 小程序全局配置
├── cloudfunctions/         # 腾讯云函数 getModel，用于获取模型 / 文物数据
├── project.config.json     # 小程序项目配置
└── README.md               # 项目文档


## 🚀 项目功能
1. 文物卡片列表展示，点击进入详情页
2. 3D文物模型在线预览、旋转查看
3. 文物介绍文字、图片资料展示
4. 文物收藏功能
5. 多页面路由、自定义底部Tab栏

## 💡 项目收获 & 面试可讲亮点
1. 在小程序受限Web环境下，基于Three.js完成GLB模型解析与WebGL渲染，处理模型加载、资源异步加载逻辑；
2. 使用腾讯云开发云函数，实现前后端分离，动态返回文物元数据；
3. 处理移动端3D渲染性能优化，控制模型面数，避免小程序内存溢出；
4. 工程化取舍：大体积模型不上传Git，区分源码与静态素材，理解Git仓库不适合存储大二进制文件。

## 📌 启动说明
1. 使用微信开发者工具导入项目，打开`project.config.json`
2. 云开发部分需要重新开通云环境、重新部署云函数（原云环境已过期）
3. 3D模型：需要手动放入`glb_head.bin`模型文件，新版本微信存在兼容性问题。
