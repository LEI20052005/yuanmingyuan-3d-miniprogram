# 图标文件说明

为了完整运行小程序，请在 `miniprogram/images/` 目录下添加以下图标文件：

## 标签栏图标

1. **推荐.png** - 导览图标（未选中状态）
   - 尺寸：81x81 像素
   - 格式：PNG
   - 建议：使用简单的房子图标

2. **鉴赏.png** - 鉴赏（选中状态）
   - 尺寸：81x81 像素
   - 格式：PNG
   - 建议：与 home.png 相同但颜色不同

3. **首页.png** - 首页图标（未选中状态）
   - 尺寸：81x81 像素
   - 格式：PNG
   - 建议：使用扳手或工具图标

4. **修复.png** - 修复图标（选中状态）
   - 尺寸：81x81 像素
   - 格式：PNG
   - 建议：与 repair.png 相同但颜色不同

5. **我的.png** - 我的图标（未选中状态）
   - 尺寸：81x81 像素
   - 格式：PNG
   - 建议：使用齿轮图标

6. **settings-active.png** - 设置图标（选中状态）
   - 尺寸：81x81 像素
   - 格式：PNG
   - 建议：与 settings.png 相同但颜色不同

## 图标设计建议

- **未选中状态**：使用灰色 (#7a8a99)
- **选中状态**：使用蓝色 (#4a90e2)
- 图标风格：简洁、扁平化
- 背景透明

## 临时解决方案

如果暂时没有图标文件，可以：
1. 使用在线图标生成工具创建简单图标
2. 从 iconfont 等图标库下载
3. 或者暂时注释掉 app.json 中的 tabBar 配置
